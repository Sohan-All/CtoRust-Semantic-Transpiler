# `anthropic[vertex]`, not plain `anthropic`: llm.py's Claude path uses
# AsyncAnthropicVertex, which imports google.auth, and that arrives only with
# the extra. Installing plain `anthropic` fails at client construction partway
# into a run rather than at import — the worst place to learn about it.

# Each cap is the NEXT major after the verified version, not an arbitrary
# ceiling: with bare `>=` floors a fresh install resolved openai 3.24.0 and
# anthropic 1.11.0 — both a major past anything this code has run against,
# and neither verified here. Patches and minors are still free to float.
